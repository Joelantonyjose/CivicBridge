About CivicBridge

Connecting citizens and local representatives to build safer, cleaner, and stronger communities.

🎯 Our Mission

CivicBridge empowers citizens to report local issues, track their progress, and encourage timely resolution through better communication between communities and local representatives.

🚀 Key Features

  • Report civic issues quickly and easily.
  • Track issue status from Pending to Resolved.
  • Search and filter reported issues.
  • Community dashboard with live statistics.
  • Modern, responsive user interface.

🛠️ Technologies Used

  • Python
  • Flask
  • SQLite
  • HTML5
  • CSS3
  • Jinja2 Templates
  • Git & GitHub
